Copy database objects between DataGrip connections. Review the SQL, then transfer.

TableBridge adds a familiar Copy → Paste workflow to the database tree. Select source objects, paste onto a destination database or schema, and use a three-step wizard to configure and review the transfer.

  • Tables and records: copy structure and data, structure only, or records into an existing table.
  • Per-object control: search, select, rename destinations, and review field mappings or complete destination definitions.
  • MySQL and PostgreSQL: same-engine transfer and supported cross-engine conversions, with explicit conversion notes.
  • Database objects: supported views, functions, procedures, sequences, and types; complex definitions use an editable review workflow.
  • Recovery and synchronization: optional durable checkpoints, bounded retries, primary-key insert/update, and mirror delete.
  • Execution visibility: SQL preview, dependency checks, destructive-operation confirmation, and exportable per-object results.

Getting started: refresh source/destination metadata; copy objects in the database tree with Ctrl+C (⌘C on macOS); select the destination database/schema and paste with Ctrl+V (⌘V); configure, review, and start.

Compatibility: DataGrip 2026.2 (262.*). The current version is 0.3.1-alpha. MySQL 8.0.43 and PostgreSQL 18.3 have isolated integration-test evidence. Oracle paths are experimental and have not passed real-database acceptance. SQL Server is outside this release's supported scope.

Boundaries: arbitrary dynamic SQL, complex collations, vendor-specific types, and ambiguous overloads are not promised to convert automatically. Checkpoint/sync mode requires matching complete primary keys and destination staging space; MySQL destinations require InnoDB. Existing triggers and constraints remain active. DDL can commit implicitly and failures may leave structures; this plugin is not a database backup tool.

Database authentication stays with DataGrip. TableBridge does not add a password store or cloud transfer service. Review definitions and test with disposable data before important transfers.
