This is an edited walkthrough of the actual plugin UI in an isolated DataGrip SDK environment, using sample metadata. It does not execute a database transfer. English prompts and Chinese captions are included; there is no audio.

MySQL and PostgreSQL paths have isolated integration-test evidence. Oracle paths are experimental and have not passed real-database acceptance. SQL Server is outside this release's supported scope. Complex definitions may require manual SQL review.
