# TableBridge（DataGrip 2026.2 开发版）

用户已安装版本 `0.2.4-alpha`；当前源码为未完整交付的 `0.3.0-dev`。在数据库树复制对象，在目标数据库/schema 粘贴，进入三步传输向导。
支持同类型连接之间复制，并提供首版 MySQL ↔ PostgreSQL 表转换。

## 构建、安装和使用

```sh
python3 tools/build.py --test
```

默认使用本机 `/Applications/DataGrip.app/Contents` 的 SDK/JBR，匹配 262.*。
安装 ZIP：`dist/tablebridge-0.2.4-alpha.zip`。DataGrip 设置 → 插件 → 从磁盘安装，随后重启。

1. 在数据库树选择同一模式中的对象，Ctrl+C（macOS ⌘C）。
2. 选择目标数据库/schema，Ctrl+V（macOS ⌘V）。
3. 确认源与目标连接，在对象页勾选对象、选择自动/高级配置。
4. 查看摘要、执行 SQL、转换/依赖说明，然后开始。

SQL 编辑器、数据网格和普通文本复制不受影响；剪贴板仅存对象引用，不含表记录或认证信息。

## 0.2 功能

### 同类型复制与依赖

- MySQL、PostgreSQL、Oracle、SQL Server 各自同类型连接间复制。
- 表、视图、函数、存储过程、序列和类型分组。读取已加载的 DataGrip 元数据。
- 自动/高级模式；按表改名、仅结构或结构和数据；搜索保留勾选。
- “补选依赖”选择当前模式已加载的序列和直接/间接外键引用表；外键需勾选“复制外键”。缺少可识别外键依赖时，计划阶段提示。
- PostgreSQL nextval/serial 默认值自动加入独立目标序列，支持同模式改名复制。使用确定性的 UTF-8 长度受限名称；冲突时改用后缀，避免复用来源序列。
- PostgreSQL 导入后按目标数据和序列方向调整自增值，不主动降低已有序列值；显式 MySQL 自增值 0 得以保留。
- 同数据源可识别的同服务器路径使用 INSERT SELECT；其他情况参数化分批复制。

### 已有目标表

在对象页选择“目标表已存在时”：

| 选项 | 行为 |
|---|---|
| 停止并提示（默认） | 计划生成失败，不覆盖 |
| 追加数据 | 保留已有结构和记录；主键/唯一冲突报错，不自动更新或忽略 |
| 清空数据后复制 | 使用 DELETE，保留结构；先校验字段与依赖 |
| 删除并重建表 | 明确 DROP TABLE 后生成新结构；不使用 CASCADE |

- 这些策略仅作用于已内省到的同名**表**，非表对象仍拒绝覆盖；不存在的目标正常新建。
- 所有来源和已有目标字段预检查后才开始执行。清空/重建和跨类型转换需在摘要页勾选确认。
- MySQL 清空要求 InnoDB；被外键引用的目标表会拒绝自动清空，避免隐式级联。不会关闭外键检查。
- 来源/目标同名同模式时，运行前验证服务器身份，防止连接别名造成自覆盖。PostgreSQL 若无权读取 pg_control_system，会要求目标改名；Oracle/SQL Server 身份相同的独立克隆环境可能被保守拒绝。
- 不自动重试失败项目或重复执行完成计划。重新执行必须重新复制并生成计划。

### 首版跨类型表转换

- MySQL ↔ PostgreSQL：显式转换字段、可空性、主键、简单默认值、自增列和记录。
- 显示逐字段映射；包括无符号整数扩大范围、精确 decimal/numeric、字符串、二进制、常见日期/时间戳和 JSON；PostgreSQL UUID 映射到 MySQL char(36)。
- 为避免不明确的转换，计算列、未知默认表达式、无界 numeric、带时区时间、多位 BIT、MySQL TIME 区间语义及 enum/set/空间等未支持类型会在计划阶段拦截。
- 首版不迁移其他索引、唯一/检查约束、注释、排序规则、触发器、权限；说明页列明并要求确认。跨类型外键、视图、函数、存储过程、独立序列及类型对象暂不转换。
- Oracle/SQL Server 的跨类型迁移尚未实现。

### 执行结果

- 逐对象显示阶段/结果、已处理行数、耗时、是否确认提交和失败原因。
- 后置索引/约束失败不会显示为成功；区分未执行、取消、部分完成与已提交。
- 窗口内和 IDE 后台任务均可取消，向活动 JDBC Statement 传递取消请求；连接建立期间可能需要等待驱动响应。
- 可以导出结果及日志为 UTF-8 文本。完成后请求目标内省，刷新失败会记录提示。

## 仍有的限制

- 必须先内省/刷新；使用已加载元数据，不能代替数据库备份。认证继续由 DataGrip 管理。
- 目前真实端点集成测试仅覆盖隔离 MySQL 8.0.43；PostgreSQL/Oracle/SQL Server 尚未完成实际端点验收。跨类型方向尚未完成双端真实数据库端到端测试。
- Oracle identity 数据、PostgreSQL 同模式改名 identity 表的显式序列名、同名重载函数尚不支持；PostgreSQL serial 与 identity 是不同情况。
- 不自动改写函数体/动态 SQL；跨模式/三段式引用无法可靠迁移时拒绝。依赖补选只覆盖识别到的外键和序列，不保证视图/过程的任意依赖闭包。
- ARRAY、STRUCT、REF、SQLXML 等复杂 JDBC 值不支持流式记录复制；LOB 单元格整体读取。
- 每对象独立提交；MySQL/Oracle DDL 隐式提交可能留下部分结构。重建失败可能已删除旧表，摘要明确提示，不保证全任务回滚。既有目标触发器按数据库正常语义执行。
- 无全库原子快照；不保证并发修改来源/目标时结果一致。行数校验不等同内容逐字节比对。
- 序列调整本身不是事务回滚保证；单独复制序列的参数来自已加载的元数据。
- 配置保存/加载、增量同步、断点续传、自动失败重试尚未实现。

## 验证

- `CoreTest` / `FeatureTest`：654 项断言，包含 603 行保真检查，不是 654 个独立测试用例。
- `PlanSmoke`：在实际 DataGrip 内用原生模型生成 serial 依赖、跨类型 DDL 和已有表策略；完整向导确认状态与渲染。
- `UiSmoke`：生产 Swing 对象面板的搜索、勾选、模式切换和验证交互。
- `MySqlIntegration`：实际本机独立 MySQL，先验证服务器 datadir 完全等于指定的任务测试目录才执行写入。验证复制、追加冲突、清空回滚、级联拦截、生成 DDL、自增值、Unicode/decimal/binary 和取消。只用于可丢弃测试目录。

```sh
python3 tools/sdk_smoke.py
DATAGRIP_PROPERTIES="$PWD/build/sdk-smoke/idea.properties" \
DATAGRIP_VM_OPTIONS="$PWD/build/sdk-smoke/datagrip.vmoptions" \
/Applications/DataGrip.app/Contents/MacOS/datagrip dontReopenProjects
```

该实例的配置和插件均在 build 内，测试类不会进入发行 ZIP。
验证结果与实际限制见 `docs/VALIDATION.md`。

实现依据：[PostgreSQL INSERT](https://www.postgresql.org/docs/16/sql-insert.html)、[序列函数](https://www.postgresql.org/docs/15/functions-sequence.html)、[MySQL 外键约束](https://dev.mysql.com/doc/refman/8.0/en/create-table-foreign-keys.html)。


## 0.3.0-dev 开发状态（未安装）

此开发包仍在补齐用户要求的全部功能，不能当作完整交付版。SQL Server 不在后续开发范围。当前已接通配置保存/加载（v3，兼容 v1/v2，不存认证信息）、高级字段映射（目标类型、明确省略默认值、计算值物化）、跨库普通/唯一索引、外键、表注释与后置结构的依赖顺序。

可选全量内容校验在提交前扫描来源和目标，核对包括重复行、NULL、数值、二进制和时间的记录摘要；追加复制包含目标原有记录。默认关闭，因为会额外读取数据。JSON 原生类型校验会统一对象键顺序并保留数值精度；明确映射为文本时按文本原样比较。PostgreSQL JSON/JSONB 默认映射到 MySQL LONGTEXT，避免原生 JSON 数值舍入；目标类型变化会列入计划。TIME 使用保留微秒的通道。

当前源码已加入 Oracle 跨类型标量映射及 Oracle DATE/时间默认值处理，但 Oracle 测试连接不可用，未通过 Oracle 实库验收。已加入跨库字段注释与基础检查约束；任意方言检查表达式仍需补齐。MySQL 元数据注释中的补充 Unicode 字符会被数据库替换，现已在执行前拒绝。尚未补齐非表对象跨方言转换、排序规则/触发器、完整时区和复杂类型策略、identity 特殊场景、重载对象、函数/视图依赖改写、可靠重试/恢复/增量复制和整任务恢复。原生同模式复制的索引/约束名称冲突也需要补齐。完整验收前保留用户的稳定安装。


基础跨库 SELECT 视图已接入开发版计划生成，依赖必须补选，创建时限定为目标模式，并保留来源表引用别名以支持改名复制；选中视图按依赖拓扑顺序创建，循环依赖在执行前拒绝。当前接受已加载的 SELECT 源码和基础 CREATE [OR REPLACE] VIEW 名称 AS SELECT 包装（仅生成目标 CREATE，不覆盖已有视图）；CTE/嵌套查询、函数调用、逗号关系和方言语法仍需扩展。基础视图新增路径已通过双向隔离实库测试和原生 SDK 源码模型计划验收，不代表任意视图已支持。


带时区 timestamp 现按原生类型名识别（含 JDBC 将 timestamptz 报为普通 TIMESTAMP 的情况），通过 OffsetDateTime 写入，摘要按 UTC 时间点比较。PostgreSQL 同类型复制已验证 JDBC/原生通道及微秒/NULL；跨到 MySQL 默认映射为 VARCHAR(64) 保留偏移文本，计划显示类型变化。Oracle 区域时区/NLS 与 TIME WITH TIME ZONE 仍需扩展，不宣称完整时区功能完成。

## 0.3.0-alpha 本次交付

用户要求排除 Oracle 实库测试与验收，完成其他功能后安装。当前交付包含同类型/跨连接复制、自动转换与手工审核入口、完整结构、字段映射和特殊值保真、重载签名识别、依赖/名称保护、持久检查点与恢复、有限重试、主键增量及镜像同步。复杂 SQL 不承诺自动等价：动态依赖、重载调用歧义或无法原生对应的类型进入手工定义流程；MySQL 无独立序列/TYPE 时明确提示。PostgreSQL 可延迟的循环外键可在同一事务延迟校验；非延迟循环在写入前拒绝，未禁用外键。

771 项核心断言、2545 项 MySQL/PostgreSQL 隔离实库检查与 DataGrip 2026.2.6 SDK 原生模型/配置/界面通过，新增实际终止目标会话、丢失提交确认、独立 JVM 恢复、APPEND 内容核对及原生驱动暂存。配置 v6 保存参数签名与断点选项，兼容 v1–v5。同名重载批量迁移需不同目标名及审核定义；没有主键的表保持普通复制，不能自动断点/同步。

Oracle 代码路径含身份列加载策略恢复及边界重置、区域/本地时区传输，但 Oracle 实库验收按要求排除，仍标记未验收。已有 Oracle identity 表的追加/同步、任意复杂 Oracle 类型/程序、权限迁移不作为自动支持承诺。SQL Server 没有新增开发。定时任务保持关闭。

安装包：dist/tablebridge-0.3.0-alpha.zip。安装前备份记录在 build/install-backups。DataGrip 运行中的会话保留，重启后加载新版。
