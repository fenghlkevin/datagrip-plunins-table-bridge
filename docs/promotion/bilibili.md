# DataGrip 跨库复制表：TableBridge 插件 56 秒界面演示

## 简介

TableBridge 已上架 JetBrains Marketplace，为 DataGrip 数据库树提供对象复制粘贴入口。本视频展示目标确认、对象选择、高级配置、结构定义与执行前 SQL 审核。

视频使用真实插件界面与示例元数据，不执行数据库传输；包含中文字幕，无音频。

插件免费使用，源码未公开。目前为 alpha，兼容 DataGrip 2026.2（262.*）。MySQL 与 PostgreSQL 已有实库验收记录；Oracle 为实验性能力，SQL Server 不在当前支持范围。

如果你平时使用 Navicat，也可以了解这个直接在 DataGrip 中操作的方案。

安装：https://plugins.jetbrains.com/plugin/34687-tablebridge--database-object-copy
