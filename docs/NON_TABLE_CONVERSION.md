# 非表对象跨库转换

本轮实现用户选定的“可转换对象自动处理，其他对象提供预览和手工修改入口”。这是 0.3.0-dev 的开发功能，尚未覆盖用户已安装的 0.2.4-alpha。用户关闭的定时任务保持关闭。本轮未继续开发 SQL Server。

## 使用

复制数据库树对象，在目标模式粘贴；选择对象页点击对象名称 → 高级 → 转换定义。

编辑器左侧为来源 DDL（只读），右侧为目标 CREATE（可修改）。支持的对象打开时自动尝试生成；失败显示具体原因，可以编辑目标定义或取消勾选该对象。依赖列表可多选，保存后补选这些对象；计划按依赖顺序创建，循环或缺少依赖在执行前报错。清空手工定义恢复自动转换。

保存后还须点击下一步审核完整计划，再由用户开始传输。保存定义不会执行数据库 SQL。修改目标名称/模式后必须重新审核定义，不能让手工 SQL 指向旧目标。

配置格式 v4 保存目标 SQL、依赖、名称和字段映射，兼容 v1/v2/v3。不保存 JDBC 认证信息或数据库记录；手工 SQL 是用户自行输入的源代码，配置文件会包含这些源代码。

## 范围

| 对象 | 自动转换 | 手工入口与边界 |
| --- | --- | --- |
| 视图 | 基础 SELECT、显式 JOIN、标识符方言转换、目标关系改名、依赖排序 | CTE、嵌套查询、函数调用和方言表达式可写目标 CREATE VIEW；依赖由用户明确选择 |
| 函数 | 单个 RETURN/SELECT 标量表达式；IN 参数；部分数值/字符串函数；按目标类型重建签名 | 数据访问、流程控制、OUT/默认/可变参数、复杂语言/权限语义需编辑；Oracle 约束形式参数需手工审核 |
| 存储过程 | 不声称有通用自动语言转换 | 提供来源和目标编辑，支持完整目标 CREATE PROCEDURE 的过程块、参数、事务及异常代码；保留其目标 SQL，不盲改程序体 |
| 序列 | PostgreSQL ↔ Oracle 的已加载 next/步长/边界/缓存/循环参数 | 必须暂停写入并刷新来源，内省 next 不是原子运行快照；MySQL 无独立原生序列，明确拒绝，不自动仿真 |
| 类型 | PostgreSQL/Oracle 间的标量属性复合/对象类型 | 枚举、集合、域、嵌套类型和方法语义需要用户提供目标定义；MySQL 无独立原生 TYPE，明确拒绝，不自动展开 |

手工入口接受一个对应类别、对应目标模式/名称的 CREATE 定义；不允许 CREATE OR REPLACE、多个无关对象或 DROP/ALTER 脚本。过程块内分号、PostgreSQL dollar-quoted 程序体、Oracle 命名 END 可使用。客户端 DELIMITER、SQL*Plus / 和多对象安装脚本需先拆分/移除；类型定义与额外 TYPE BODY 不作为一个复合脚本执行。已有非表对象仍明确拒绝覆盖。

重载对象按参数签名显示并保存至配置/恢复计划。批量迁移要求独立目标名及审核后的目标定义；自动引用中存在重载歧义时要求先明确调用签名。旧配置没有签名且存在同名对象时拒绝加载，防止套到另一对象。自动转换不自动传播 GRANT、DEFINER、SECURITY 或外部包/扩展。函数参数/返回精度、空字符串及运算语义需要用户在计划和目标调用中审核，不承诺任意程序等价。

Oracle 参数声明不接受直接长度/精度约束，故不会生成无效的受限形参；依据：[Oracle 19c Subprogram Parameters](https://docs.oracle.com/en/database/oracle/oracle-database/19/lnpls/subprogram-parameters.html)。Oracle 原生端验收仍未完成，测试连接不可用，不将规则检查冒充 Oracle 实库通过。

## 验证

- 核心 741 项断言通过，含定义绑定、引号/大小写、额外语句拒绝、配置 SQL/依赖往返和转换规则。
- MySQL/PostgreSQL 隔离矩阵 2490 项检查通过，包括真实创建/调用两方向标量函数，手工转换两端过程，PG 序列 next/步长、Oracle 风格元数据生成的 PG 复合类型，以及既有数据保真/视图/结构回归。Oracle 风格元数据不是 Oracle 源端实库验收。
- DataGrip 原生模型验证序列、函数、对象属性、手工过程的计划生成与依赖顺序；生产编辑器渲染通过，截图 build/sdk-smoke/ui-object-conversion.png。
- 不连接业务数据库。两个项目隔离数据库均先核对数据目录，测试模式 finally 清理，实例停止；独立 SDK IDE 配置位于 build/sdk-smoke，未修改用户安装。

其他未完成范围：完整结构（触发器、排序规则、高级索引等）；完整特殊字段/identity；更全面的自动依赖、重载和名称冲突；重试、断点、恢复、增量同步；Oracle 真实数据库矩阵。SQL Server 不在范围。
