# 浏览器上传易错环节

以最新界面状态操作，不复用历史辅助功能元素编号。用户指定 Safari 时使用能控制 Safari 的工具，不擅自迁移登录会话。若使用 browser-act，先加载其技能。

- macOS 文件选择器可用 Cmd+Shift+G 输入确切绝对路径，再根据最新界面确认文件；上传后检查显示的文件名与版本。
- React 表单的程序化 setValue 不一定触发保存。使用工具支持的真实输入/粘贴，移开焦点后读取值，确保与预期相同。
- 点击 Save 后等待保存结束及服务端资源 ID/版本条目出现。立刻刷新可能中止保存；不能以页面仍显示刚填内容作为持久化证明。
- 同名素材重复选择有时不会触发 file input 的 change；确认上传未发生后，使用有意义的新文件名再试，勿盲目重复。
- 上传超时或页面断开先检查已有版本及上传记录。相同版本可能已成功，不能直接重复提交或创建另一个条目。
- 素材重排只用实际工具支持且已验证的动作；拖动不生效时报告限制，不能伪称顺序已经调整。
- 重新打开编辑页确认截图和视频 URL 已保存。公开页待审核更新时同时保留后台证据，分别报告保存成功与公开展示状态。

审核邮件中的 Compatible 是兼容性结果，并不证明商店审核通过。记录 scheduled-for-removal/deprecated API 警告及对应版本，按项目范围修复或明确留下，不编造零警告。
