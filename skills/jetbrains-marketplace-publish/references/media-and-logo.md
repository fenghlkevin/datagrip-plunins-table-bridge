# 素材交付

## Logo

官方要求 SVG，尺寸 40×40，默认名称 pluginIcon.svg，主 JAR 中 META-INF/pluginIcon.svg；可选同目录 pluginIcon_dark.svg。源码常见位置为 src/main/resources/META-INF。可见图形外围至少预留 2px 透明边距，检查 40px 和 80px、浅色与深色背景。官方建议文件尽量小（约 2–3KB），不建议自动位图描摹导致超大 SVG。

设计应反映插件用途，少细节，缩小后仍可辨认。PNG 可以是设计参考，交付需要简洁的矢量路径。先渲染 SVG 检查外观，再检查打包结果：源码存在并不证明构建脚本已经包含它。离线脚本检查尺寸与明显的位图包装/外链，不证明透明边距或视觉质量。

Logo 发布验收记录分别写：源码完成、包内验证、包已上传、商店显示确认。审核中允许最后一项待核验，但不能把四项合并为“已上架”。

## 图片与视频

使用真实插件界面、隔离测试数据，隐藏真实业务信息和凭据。不得用重绘界面冒充实际产品截图。SDK 演示或模拟执行应清楚标注，成功结果只能来自实际执行。

检查每张截图的语言，包括 SQL 注释、错误说明和底部状态。原始数据库对象名和数据不必翻译。视频应覆盖复制、选择目标、配置对象、确认、结果；按实际产品能力调整。对编码后的成片检查开头、每个步骤及结尾，确认字幕、界面语言、分辨率、时长与音轨符合内容，不只检查生成帧。

上传 YouTube 时区分草稿、已发布、不公开列出、公开与私享。以用户授权决定可见性；确认可播放链接后再关联 Marketplace。已发布视频不能原地替换二进制；修订时上传新视频并更换商店关联，旧视频和草稿是否删除另行判断授权。不要自动开启首映。

## 本项目的可延续选择

TableBridge 此前要求保留中文截图、增加英文截图，公开英文视频并关联商店，保留源码。延续此项目时以 docs/marketplace-upload.json 等最新记录为准，不把这些选择当成所有插件的默认授权。
