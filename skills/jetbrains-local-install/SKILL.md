# JetBrains 插件本地安装

按用户指定的 IDE 安装确切版本，保留可恢复备份。只要求编写技能或准备安装包时，不顺带修改用户 IDE。

## 安装前

读取项目构建、验收与安装记录。定位实际 IDE 应用及 product-info.json，核对 buildNumber 与插件 META-INF/plugin.xml 中的 since-build/until-build、插件 ID、版本与依赖。区分用户正在使用的 IDE 与隔离 SDK 测试实例，不能把安装到测试实例当作交付。

使用已验收的最终包，记录 SHA-256。如果重新构建，按项目要求执行检查。检查主 JAR 中的 Logo，确认 META-INF/pluginIcon.svg，必要时 pluginIcon_dark.svg；SVG 应为 40×40，目视检查浅深背景。缺少 Logo 应修复并重新构建，不能只复制 PNG 到安装目录。

读取 [安装与恢复](references/install-and-rollback.md) 决定操作方法。先列出目标插件目录中所有同 ID 插件，包含名称改变后的旧目录；不要仅按目录名猜测，也不要覆盖其他插件。

## 安装

优先使用 IDE 的 Install Plugin from Disk 功能，选确切文件。已确认离线目录部署更适合且获得本地安装授权时，可以在 IDE 停止后部署。备份所有将替换的同 ID 插件及安装记录到任务目录的时间戳子目录，记录原路径和哈希；不备份密码或无关 IDE 配置。

不强制杀死用户进程。需要退出 IDE 时，确保用户工作可以保留；无法确认未保存工作时请用户保存并退出，继续独立准备。文件系统权限按工具流程处理。使用临时目录安全解包，拒绝绝对路径、路径穿越及越界符号链接。先验证目录布局和描述文件，再替换目标同 ID 插件。保留备份直到用户确认稳定。

## 验收与记录

安装到磁盘、IDE 重启、插件成功加载是不同状态。重启前只报告“已安装，等待重启”。重启后读取插件管理器/启动日志，确认确切 ID 和版本，查看 Logo 以及项目相关动作是否注册。使用隔离或无数据库写入的 UI 检查；安装验收不授权业务数据传输。

失败时保留错误证据，停止重复覆盖。按备份清单恢复原版本，再确认加载；不能通过删除整个 plugins 目录解决问题。

在项目安装记录保存：IDE 路径/build、插件 ID/version、包 SHA-256、安装路径、备份路径、检查结果、重启与加载状态、Logo 展示证据及未完成事项。不声称通过未执行的实库验收，不把本地安装当作 Marketplace 发布。
